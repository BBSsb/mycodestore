# 电商智能客服AI Agent

基于LangGraph和Streamlit构建的电商智能客服系统，具备意图识别、订单查询、物流查询等功能。

## 功能特性

- 🤖 **多Agent工作流**：基于LangGraph构建的智能对话系统
- 🔍 **意图识别**：自动识别用户咨询意图（订单查询、物流查询、商品咨询、售后服务等）
- 📦 **订单查询**：支持订单状态、详情查询
- 🚚 **物流查询**：支持物流进度跟踪
- 💬 **智能对话**：支持自然语言交互
- 🇨🇳 **国产大模型**：集成通义千问（Qwen）大语言模型
